Como funciona

Três passos. Você no controle de cada um.

01

Deslize para revisar

Uma foto de cada vez. Deslize para a direita para guardar uma memória, para a esquerda para deixá-la de lado para revisão. Desfaça qualquer coisa, a qualquer momento.

Guardar →
02

Revise a lista

Nada foi excluído ainda. Tudo que você deixou de lado cai em uma lista de revisão, onde pode olhar de novo e tirar fotos dela.

← Revisar para excluir
03

Confirme para excluir

Só quando você toca em confirmar é que o PhotoLess remove as fotos selecionadas. Recuperável em Apagados Recentemente, como sempre.

Bom saber

Perguntas, respondidas com clareza.

Deslizar exclui minhas fotos na hora?

Não. Deslizar só adiciona uma foto a uma lista de revisão. Nada é removido até você olhar a lista e confirmar.

Minhas fotos são enviadas para algum lugar?

Nunca. O PhotoLess não tem servidores nem nuvem. Suas fotos são lidas no seu aparelho, só para serem mostradas a você.

Ele usa IA para olhar minhas fotos?

Nenhuma IA vê suas fotos. O PhotoLess só as mostra a você em um fluxo calmo, uma de cada vez, para você decidir.

Posso recuperar uma foto depois de excluí-la?

As exclusões passam pelo fluxo padrão do seu aparelho, então as fotos removidas costumam ficar em "Apagados Recentemente" por um tempo antes de sumirem de vez.

O PhotoLess é grátis?

Sim — as sessões diárias de revisão são grátis, e os recursos de segurança (desfazer, revisar, confirmar) sempre serão. O Premium libera revisão ilimitada e as ferramentas do Studio.

Preciso de uma conta?

Sem conta, sem e-mail, sem login. Abra o app e comece — o PhotoLess nunca sabe quem você é.

Limpe a bagunça, não as memórias.

O PhotoLess já está disponível para iPhone. Calmo, privado e reversível até você decidir.
